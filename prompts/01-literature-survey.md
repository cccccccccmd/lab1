# S1 文献调研与 Gap 挖掘

> 目标：不是"综述"，而是**为创新点探索提供弹药**。产出 `SURVEY.md`，核心交付物：领域时间线、领域假设清单、领域世界观分析、≥3 个高质量研究 gap。
> 深度标准：调研结束时，你应当能**不看任何资料**，向一位相邻领域的教授讲清楚"这个领域这几年在干什么、卡在哪、为什么卡"，并回答追问。达不到这个标准就还没读够。

## 1. 信息源矩阵（多源交叉，单一来源必有盲区）

| 信息源 | 用途 | 提取什么 |
|---|---|---|
| arXiv（近 6 个月） | 前沿动态 | 新方法、新任务、新评测；扫读 30–50 篇 |
| 顶会论文集（近 2 年 oral/spotlight） | 领域公认的高价值工作 | 锚点论文池 |
| Semantic Scholar 引文图谱 | 沿引用链双向追踪 | 锚点论文引用了谁（思想源头）、被谁引用（后续修正与批评）——**批评性引用是金矿** |
| OpenReview 被拒论文 + 审稿意见 | 领域的痛点与雷区 | 审稿人反复抱怨什么；哪类想法反复被投又反复被拒、死因是什么 |
| Papers With Code 榜单 | SOTA 现状 | 榜单数字、方法谱系；**榜单停滞 = 范式可能到头，机会所在** |
| 近期 survey 论文 + 博士论文 | 结构化地图 | 别人整理好的分类学；博士论文的 future work 章节常有真诚的未解问题 |
| 顶会 workshop 议题 | 领域风向标 | workshop 主题是"共同体觉得重要但主会还没解决"的问题清单 |
| SOTA 方法开源仓库的 Issues | 真实失效案例 | 用户报告的 bug 和"在我的数据上不 work"——现实世界的失败模式，论文里看不到 |

检索纪律：每个信息源的检索词、日期、看过但排除的论文记录在 `SURVEY_TRACE.md`（S2 新颖性检查的底账，防止重复劳动）。

## 2. 三级阅读法（按投入递增，明确每篇读到哪一级）

- **L1 扫读**（10 分钟/篇，30–50 篇）：摘要 + 图 1 + 主表。只回答：它声称什么？数字可信吗？值得升级到 L2 吗？
- **L2 方法级**（30–45 分钟/篇，10–15 篇）：方法 + 实验 + 消融。填写下方八项卡片。
- **L3 复述级**（2–4 小时/篇，5–8 篇锚点论文）：关键公式/算法**亲手重新推导一遍**；然后用自己的话把方法"讲给一个聪明的本科生"（写成 200 字以内的直觉解释，存入卡片）。**讲不顺、推不出的地方，要么是你的理解缺口，要么是论文自己没讲清——后者往往就是机会。**

## 3. 八项卡片（L2 以上论文必填，每项 ≤2 句话——字数上限是逼迫压缩出信息密度）

1. **核心 claim**：作者声称什么（区分"证明了"与"展示了"）。
2. **关键假设**：方法成立依赖哪些显式与**隐式**假设（隐式假设是创新点富矿："假设检索文档相关"、"假设 reward 无噪声"、"假设错误彼此独立"）。
3. **机制一句话**：它**为什么**work？（作者的解释是什么？这个解释有对照实验支持吗，还是只是叙事？）
4. **实验没覆盖什么**：回避了什么设置/规模/对比？主表里最弱的格子在哪？
5. **数字细节**：提升几个点？来自哪个组件（读消融表，不读正文声称）？提升是否随规模/数据量变化？
6. **Limitations 与外部批评**：作者承认的 + 审稿人/后续论文指出的。
7. **如果我是作者，下一篇做什么**：站在作者视角外推一步——你想到的和他们实际做的（查后续论文）的差值，就是你对领域嗅觉的校准。
8. **这篇最可能错在哪**：如果两年后有论文推翻它，最可能攻击哪个实验或假设？

## 4. 综合分析（卡片攒够后做，这是"读过"与"读懂"的分界线）

### 4.1 领域时间线重建
按 2–3 年一波重建演化史：每一波**解决了什么问题、代价是引入了什么新问题、哪些老想法换了名字重新流行**。然后判断：当前处于范式的哪个阶段（快速上升 / 收益递减 / 等待范式转移）？收益递减期做增量改进是红海，做"指出范式局限"的分析是蓝海。

### 4.2 三张结构表
- **领域假设清单**：所有方法共同依赖的假设，逐条标注"什么现实场景下会破？破了会怎样？有人研究过吗？"
- **矛盾清单**：论文间互相矛盾的结论/数字（A 说 X 有效，B 的消融说没用）。矛盾 = 有人错了或有隐藏变量，两者都是论文机会。
- **空白矩阵**：行 = 方法家族，列 = 问题设置/数据条件/评测维度。对每个空格子诚实回答："没人做是因为不重要，还是因为难/没想到？"只有后者是机会。

### 4.3 领域世界观拷问（写入 `SURVEY.md`「世界观」一节，每题 3–5 句）
这些问题产生的是"感悟"级别的理解，也是 S2 最好的想法来源：

1. 这个领域的**隐含世界观**是什么？（它默认问题应该被怎样建模？哪些选择从没被讨论、被当作空气？）
2. 有什么问题**大家都知道存在却集体绕着走**？为什么绕（太难/不好发表/动了某个共识的奶酪）？
3. 主流**指标与真实目标的偏差**在哪？指标高但实际差的情形能构造出来吗？
4. 哪些"标准做法"其实**只有历史惯性、没有证据支持**？（顺着追问"为什么大家都这么做"，答案是"某篇早期论文这么做了"的地方要标记）
5. 一个**领域外的聪明人**看这个领域，会觉得哪里奇怪？（借用你在其他领域的知识做一次陌生化审视）
6. 如果**算力/数据突然 ×100 或 ÷100**，这个领域的方法排序会怎么变？对资源敏感的结论都是脆弱的结论。

### 4.4 信念更新日志
每个调研工作日结束时，在 `RESEARCH_LOG.md` 写 3 条「今日信念更新」：*"我原以为 X，现在认为 Y，因为证据 Z"*。没有信念被更新的一天 = 白读了，第二天换信息源或换阅读级别。

## 5. 出口产物

`SURVEY.md` 末尾给出 **≥3 个候选研究 gap**：

```
### Gap-N: <一句话描述>
- 证据：哪些卡片/矛盾/假设/世界观拷问支持它存在（引用编号）
- 重要性：解决它对领域意味着什么；谁会关心；能否一句话讲给领域外的人
- 现状：最接近的已有工作，差在哪
- Why now：为什么这个 gap 现在变得可做/重要（新模型能力？新数据？新失效证据？）——答不出这题的 gap 大概率早被人试过并放弃
- 否证设想：如果这个 gap 其实不存在，什么样的 ≤2 小时实验能最快暴露？（S2 闸门 C 的预案）
- 资源匹配度：6GB 显存 + API 下可验证性（高/中/低）
```

## 6. 纪律

- 每读一篇立即写卡片，不批量欠账；卡片遵守字数上限。
- 时间盒：主体 2–3 个工作日等效；4.1–4.3 的综合分析至少留出 1/3 时间——**读得多而不综合，是调研最常见的失败方式**。
- 不追求穷尽：S2/S3 发现文献缺口时随时回来补，`SURVEY.md` 是活文档。
- 更新 `RESEARCH_LOG.md`：阶段总结 + 进入 S2。
