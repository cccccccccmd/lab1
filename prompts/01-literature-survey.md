# S1 文献调研与 Gap 挖掘

> 目标：不是"综述"，而是**为创新点探索提供弹药**。产出 `SURVEY.md`，核心交付物是一张"领域假设清单"和 ≥3 个高质量研究 gap。

## 1. 调研策略

按以下顺序检索（使用 WebSearch / WebFetch，能访问 arXiv、Papers With Code、Semantic Scholar、OpenReview）：

1. **锚点论文**：找到方向内近 2 年被引最高 / 最近顶会 oral 的 5–8 篇，精读。
2. **前沿追踪**：arXiv 最近 6 个月的相关新论文，扫读 15–30 篇（只读摘要+方法图+主表）。
3. **失败与争议**：OpenReview 上相关方向**被拒论文的审稿意见**——这是最被低估的信息源，审稿人反复抱怨的问题就是领域的痛点清单。
4. **SOTA 榜单**：Papers With Code 相关任务榜单，记录当前 SOTA 的方法、数字、以及榜单近期是否停滞（停滞 = 现有范式可能到头了，机会所在）。

## 2. 精读方法：每篇锚点论文提取六件事

写入 `SURVEY.md` 的论文卡片，每篇必须回答：

1. **核心 claim**：一句话，作者声称什么。
2. **方法的关键假设**：方法成立依赖哪些显式或**隐式**假设？（隐式假设是创新点的富矿，例如"假设检索到的文档是相关的"、"假设 reward model 无噪声"）
3. **实验没覆盖什么**：哪些设置/数据/规模没测？作者回避了什么对比？
4. **Limitations 与审稿意见**：作者自己承认的 + OpenReview 上审稿人指出的。
5. **数字细节**：主要指标提升了几个点？提升来自哪个组件（看消融表）？
6. **我能借用什么**：可复用的基线代码、数据集、评测协议。

## 3. Gap 挖掘：从论文卡片到研究机会

完成论文卡片后，做三张汇总表写入 `SURVEY.md`：

- **领域假设清单**：整个方向的方法们共同依赖的假设，逐条标注"这个假设在什么现实场景下会破？破了会怎样？有人研究过吗？"
- **矛盾清单**：不同论文之间互相矛盾的结论/数字（A 说 X 有效，B 的消融显示 X 没用）。矛盾意味着有人错了或有隐藏变量——两者都是论文机会。
- **空白矩阵**：行 = 方法家族，列 = 问题设置/数据条件/评测维度，标出没人做过的格子，并对每个空格子诚实回答："没人做是因为不重要，还是因为难/没想到？"只有后者是机会。

## 4. 出口产物

`SURVEY.md` 末尾给出 **≥3 个候选研究 gap**，每个 gap 用如下格式：

```
### Gap-N: <一句话描述>
- 证据：哪些论文卡片/矛盾/假设支持这个 gap 存在（引用编号）
- 重要性：解决它对领域意味着什么；谁会关心
- 现状：最接近的已有工作是什么，差在哪
- 资源匹配度：在 6GB 显存 + API 的条件下可验证性如何（高/中/低）
```

## 5. 纪律

- 每读一篇立即写卡片，不要批量欠账。
- 检索词、日期、看过但排除的论文也记录在 `SURVEY_TRACE.md`（防止 S2 阶段重复检索，也是新颖性检查的底账）。
- 控制时间盒：本阶段目标 1–2 个工作日等效的量，不追求穷尽——S2/S3 阶段发现文献缺口时可以随时回来补。
- 更新 `RESEARCH_LOG.md`：阶段总结 + 进入 S2。
