# 领域包：因果机器学习（Causal ML：效应估计与因果发现）

## 0. 适配度与推荐切入角度（★★★★★）

**硬件契合度最高的领域**：主流实验是表格数据上的统计学习，CPU 或 6GB GPU 轻松承载，单实验分钟级到小时级——你可以跑得起比大多数竞争者更彻底的多种子、多设置扫描，这是实打实的比较优势。
推荐切入角度：**评测科学**（本领域基准长期薄弱，合成数据与真实世界的鸿沟是公认痛点）、**因果 × LLM 的交叉**（用 LLM 提供先验/辅助识别，新且热）、**假设违背下的稳健性**（隐藏混杂、正性违背时各方法的降级行为）。
注意：本领域数学门槛高于其他领域，理论叙述的严谨性是审稿重点——量级估算和玩具模型（S3）在此领域应升级为**正式的可识别性论证**。

## 1. 领域地图

- 两大板块：**效应估计**（ATE/CATE/ITE：从观测数据估计干预效应，代表方法 TARNet/CFR、DragonNet、双稳健/DML、元学习器 S/T/X-learner）与**因果发现**（从数据学结构：约束类 PC/FCI、评分类 GES、连续优化类 NOTEARS 及其争议）。
- 新兴交叉：因果表示学习；因果 × LLM（LLM 作为先验知识源/变量标注器）；因果视角的分布外泛化。
- 关键子问题：无混杂假设不可检验怎么办（敏感性分析）；CATE 估计的模型选择悖论（没有真值如何选模型）；发现算法在有限样本/隐变量下的可靠性；合成基准的代表性危机。

## 2. S1 定制

- 检索词族：`treatment effect estimation`、`CATE/heterogeneous effects`、`causal discovery`、`sensitivity analysis`、`causal machine learning benchmark`、`LLM causal`。
- 必读类型：CFR/DragonNet/DML 代表作；**批判 NOTEARS 类连续优化发现方法的论文**（本领域近年最重要的方法论辩论，示范了"打破共识"型论文怎么写）；基准批判论文（IHDP 等合成基准代表性的质疑）；Pearl 因果层级与 Rubin 潜在结果框架的对照综述（两大话语体系都要会说）。
- 工具生态：dowhy、econml、causal-learn——它们的 Issues 区反映实践者的真实痛点。

## 3. 评测协议与基线

- 常用基准：IHDP、ACIC 系列、Twins、Jobs（效应估计）；合成 SCM 数据 + bnlearn 标准网络（发现）。**全领域皆知这些基准有缺陷**——认真对待评测本身就是贡献机会。
- 效应估计指标：PEHE、ATE 误差；发现指标：SHD、SID、F1（注意 CPDAG 等价类处理）。
- 必备基线：效应估计必含**朴素回归调整与倾向得分类经典方法**（深度方法未必赢简单方法，本领域屡见不鲜且审稿人清楚）；发现必含 PC/GES 老将。
- 种子纪律加强版：本领域实验便宜，主结果跑 **10+ 种子/数据抽样**，报告分布而非只报均值——这是你硬件优势的直接兑现。

## 4. 领域特有陷阱

1. 合成数据的生成机制偏袒某类方法（如非线性强度、混杂结构恰好匹配你的归纳偏置）——数据生成过程必须多样化并公开全部参数。
2. IHDP 的已知问题：不同论文用的复制版本不一致、方差巨大——用它时报告协议细节并同时上别的基准。
3. "可识别性"与"可估计性"混为一谈：先说清假设下参数是否可识别，再谈估计精度。
4. CATE 模型选择用了不该有的真值信息（拿测试集真实效应调参）——本领域版本的"测试集泄漏"，用代理准则并说明。
5. 因果发现论文只测有向边准确率、回避"下游效应估计有没有因此变好"——补上下游任务评测会显著加分。

## 5. 创新点富矿（算子实例化）

- 度量质疑/评测科学：构建更接近真实的基准（半合成：真实协变量+透明效应机制）；系统评测"各方法在假设违背时的降级曲线"。
- 矛盾仲裁：深度效应估计方法在不同论文间排名不稳定——隐藏变量（数据规模？调参协议？）是什么？大规模受控复现本身即论文。
- 组合失配/交叉：LLM 的领域知识作为因果图先验，何时可靠何时有害？（与 causal-reasoning 包联动）
- 假设反转："更灵活的模型估计 CATE 更好"——灵活性带来的方差在小样本下何时压倒偏差收益？
- 极限降解：样本量降到几百（现实医疗/经济场景），哪些方法先失效？小样本因果推断研究稀疏而现实需求大。

## 6. 硬件与成本映射

- 几乎全部本地：表格数据 + sklearn/torch 小网络，CPU 与 6GB GPU 均过剩；API 仅在因果×LLM 交叉时使用。
- 单实验成本低 → 把预算花在**实验设计的彻底性**上（多种子、多数据生成机制、全面敏感性分析）——这是资源劣势领域反转为优势的地方。
