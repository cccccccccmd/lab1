# 领域包：因果推理 × LLM（Causal Reasoning with LLMs）

## 0. 适配度与推荐切入角度（★★★★★）

与 causal-ml 包是姊妹关系但问题相反：causal-ml 研究"用统计方法从数据推因果"，本包研究"**LLM 是否/如何具备因果推理能力，以及如何增强它**"。纯 API + 本地小模型对照即可开展，且领域年轻（2023 年后才成型），评测与方法都远未饱和——**综合竞争格局与资源匹配度，这可能是你七个方向中性价比最高的一个**。
推荐切入角度：**能力边界测绘**（LLM 在因果层级三层——关联/干预/反事实——各自的真实水平与失败模式）、**推理增强方法**（把形式化因果工具如 do-演算、图判据装进 LLM 工作流）、**污染free 评测**（现有基准疑似被背题，新协议需求真实）。

## 1. 领域地图

- 领域母题：LLM 是"因果鹦鹉"（复述训练语料中的因果知识）还是具备可组合的因果推理能力？
- 三条工作线：**评测线**（CLadder、Corr2Cause 类基准：给定图/数据陈述，测形式因果推理）；**能力线**（LLM 做因果发现辅助、变量间因果方向判断、混杂识别）；**增强线**（提示策略、工具调用形式引擎、微调注入因果规则）。
- 关键子问题：常识因果知识 vs 形式因果推理的解耦测量；反事实推理的一致性；因果方向判断中的语言线索捷径；LLM 因果知识作为下游任务（效应估计变量选择）先验的可靠性。

## 2. S1 定制

- 检索词族：`LLM causal reasoning`、`causal inference LLM`、`counterfactual reasoning language model`、`causal discovery LLM prior`、`Corr2Cause / CLadder`。
- 必读类型：CLadder、Corr2Cause 原文（**精读其错误分析与构造方法**——理解基准怎么造，才能发现基准的洞）；"LLM 因果能力是否只是记忆"的批判性分析；Pearl 因果层级的原始论述（评测设计的理论骨架）。
- 与 causal-ml 包联动：形式因果的工具箱（d-分离、后门/前门判据、do-演算）在那边的必读列表里，两包共用。

## 3. 评测协议与基线

- 常用基准：CLadder（分层因果问题）、Corr2Cause（相关→因果的形式推断）、各类反事实推理集；自建合成 SCM 题库（可控且免污染，本领域自建评测接受度高，因为可用形式引擎生成带真值的题）。
- 必备基线与对照：多家 API 模型 + 本地 1.5–3B 小模型（能力-规模曲线）；CoT vs 直答；**符号求解器上限对照**（同样的形式化输入，纯符号引擎全对——衡量 LLM 离形式推理的差距）；**表述改写对照**（同一逻辑换故事外衣，测的是推理还是记忆——本领域生命线）。
- 指标：分因果层级报告准确率；一致性指标（同一问题的等价表述间答案一致率；反事实与事实回答的逻辑相容率）。

## 4. 领域特有陷阱

1. **记忆污染**：公开基准的题目或其源材料可能在训练数据中——新实验必配"改写+换域"版本，准确率大跌即证明在背题（这个现象本身就值得报告）。
2. 常识因果与形式因果混测：题目既可靠常识蒙对也可靠推理做对，归因不清——用反常识 SCM（"抽烟导致成绩提高"式的虚构世界）强制切断常识通道。
3. 提示词敏感性：因果术语的措辞（"导致/影响/相关"）对结果影响大，所有对比统一措辞并做敏感性检查。
4. 二分类基准上的偏置：因果方向判断集若正例分布不均，"总答 A→B"即可拿高分——报告偏置校正后指标。

## 5. 创新点富矿（算子实例化）

- 失效挖掘：LLM 在因果层级第二层（干预）与第三层（反事实）的错误模式分类学——哪类图结构/哪类问句系统性出错？
- 机制追问：CoT 对因果题的增益来自真推理还是"更长的答案更容易碰到关键词"？用中间步骤忠实性检验。
- 组合失配：LLM（读题建模）+ 符号因果引擎（形式推演）的流水线为何还没有成熟范式？接口处的翻译错误（文本→图）是瓶颈？——"LLM 当解析器、引擎当推理器"的分工研究。
- 度量质疑：设计抗记忆、抗捷径的因果推理评测协议（程序化生成 + 改写不变性 + 反常识世界）——benchmark 论文机会明确。
- 极限降解：小模型（1.5B）经因果规则微调能否在形式因果题上追平未微调的大模型？（本地 QLoRA 可做，性价比故事）

## 6. 硬件与成本映射

- 评测线全 API：合成题库数千题 × 多模型 × 多表述版本，单轮数十万到百万 token，成本温和。
- 符号引擎（dowhy/pgmpy 的识别模块、自写 d-分离判定）本地 CPU。
- 本地 GPU：1.5–3B 模型 QLoRA 注入因果推理规则（合成题微调），以及能力-规模曲线的小模型端点——6GB 舒适区内。
