# 领域包：生成模型（Generative Models：扩散/流匹配/一致性等）

## 0. 适配度与推荐切入角度（★★★☆☆）

CIFAR-10/64px 级别的扩散模型本地可训（数小时到一两天一轮），这恰好是**方法与机制研究的标准试验场**——本领域大量顶会论文的核心实验就在这个规模完成。不可行的是高分辨率大规模刷 SOTA（FID 军备竞赛）。
推荐切入角度：**采样效率与训练动力学的机制研究**（小规模即可验证，理论+实验双轮）、**流匹配/一致性模型等新范式的分析与改进**（范式新、空白多）、**离散扩散**（文本/结构化数据上的扩散，竞争尚不饱和）。避开：文生图应用层微调（拼数据拼算力）、视频生成（纯算力游戏）。

## 1. 领域地图

- 主线演化：GAN/VAE → DDPM 扩散 → 噪声调度与采样器改进（EDM 系统化）→ 流匹配（flow matching，更简洁的训练目标）→ 一致性模型/蒸馏（少步生成）→ 当前焦点：**少步高质量采样、离散数据扩散、扩散与自回归的统一视角、可控性**。
- 关键子问题：训练目标/噪声调度/采样器三者的解耦分析；少步生成的质量-步数前沿；引导（guidance）的机制与副作用；扩散模型的记忆化与泛化；离散空间的扩散建模。

## 2. S1 定制

- 检索词族：`diffusion model`、`flow matching`、`consistency model`、`few-step sampling`、`discrete diffusion`、`guidance`。
- 必读类型：DDPM、EDM（设计空间系统化，本领域方法论范本，必精读到 L3）、流匹配与一致性模型原文；**理论-实验结合的分析型论文**（如研究扩散模型泛化/记忆化的）是你的对标物。
- 本领域数学密度高：L3 复述级阅读（亲手重推导）在此领域不是可选项而是必需——推不动的论文不要引用其结论。

## 3. 评测协议与基线

- 标准试验场：CIFAR-10（32px）、FFHQ/AFHQ 64px、ImageNet 64px（本地勉强，可子采样）；离散方向用 text8/小分子数据集。
- 指标：FID（注意实现一致性——用统一的评测包和参考统计量，不同实现的 FID 可差 1–2 分）、IS、少步设置下的 FID-vs-NFE 曲线；离散方向用困惑度/有效率。
- 必备基线：DDPM/EDM 标准配置（用公认开源实现，逐项对齐其报告数字后冻结）、目标范式的官方实现。
- 3 种子纪律照常，但注意生成模型训练一轮成本高——用小规模先扫方向、只在最终配置跑满 3 种子。

## 4. 领域特有陷阱

1. FID 的实现差异与样本量敏感性（5k vs 50k 样本 FID 不可比）——全文统一协议并写明。
2. 采样器改进与训练改进混淆归因：换了采样器又动了训练目标，收益说不清——严格单变量。
3. 小规模结论外推风险：CIFAR 上的结论到高分辨率可能反转，论文措辞必须限定范围，加一个 64px 数据点画趋势。
4. 与最新 SOTA 比较的陷阱：审稿人问"为什么不比 XX 大模型"——定位清楚：机制研究比的是**同规模受控设置**，在引言就立好这个预期。

## 5. 创新点富矿（算子实例化）

- 机制追问：classifier-free guidance 为什么既提质量又损多样性？更精确的机制解释能否导出无副作用的引导？
- 假设反转："噪声调度需要精心设计"——某些调度差异是否被采样器自适应性掩盖/放大？
- 矛盾仲裁：不同论文对"扩散模型是否记忆训练样本"结论不一——隐藏变量（数据规模/去重/度量）是什么？
- 极限降解：训练数据砍到 1/10，FID 与记忆化如何变化？数据效率视角在本领域研究稀疏。
- 跨域嫁接：数值 ODE/SDE 求解器文献里的自适应步长、高阶方法，仍有未搬完的原理；最优传输视角对流匹配的改进空间。

## 6. 硬件与成本映射

- CIFAR 级 U-Net（~35M 参数）+ batch 64 + bf16 在 6GB 上可训；一轮完整训练（数十万 step）约 1–3 天——**用 EDM 式高效配置把单轮压到半天以内**是本领域在你硬件上的生存技能。
- 大量使用检查点续跑与后台运行；消融实验用缩短训练（1/4 step 数）先筛，幸存者再跑全长。
- API 在本领域用途小（可用于 LLM 辅助的实验分析/数据构造）；离散扩散方向可与 LLM 结合，届时 API 有用武之地。
