# 领域定制包（Domain Packs）

通用提示词（`prompts/`）是领域无关的流程引擎；本目录下每个子文件夹是一个研究领域的**定制包**，把该领域的信息源、基准、基线、陷阱和创新点富矿预先装填好，让 S1–S6 阶段一进场就有领域级的锋利度。

## 使用方法

1. 选定研究领域后，把对应的 `domains/<领域>/DOMAIN.md` 与通用提示词一起拷入研究项目。
2. 在主控提示词的「研究方向」处写明领域，并加一句：**"进入每个阶段前，除阶段提示词外同时读取 DOMAIN.md 的对应小节"**。
3. `DOMAIN.md` 与通用提示词的关系：通用提示词规定"怎么做"，领域包提供"做什么、在哪做、避开什么坑"。冲突时以通用提示词的方法论纪律为准。

## 各领域包与硬件适配度速览（RTX 4050 6GB + API）

| 领域 | 适配度 | 主要实验形态 |
|---|---|---|
| `multi-agent-collaboration/` 多智能体协同 | ★★★★★ | 纯 API，成本可控是主要约束 |
| `agent-memory/` 智能体记忆 | ★★★★★ | 纯 API + 本地小模型检索/嵌入 |
| `kg-llm/` 知识图谱 × 大模型 | ★★★★☆ | API + CPU 图算法，图谱处理本地无压力 |
| `causal-ml/` 因果机器学习 | ★★★★★ | CPU/小 GPU 即可，几乎无硬件瓶颈 |
| `causal-reasoning/` 因果推理 × LLM | ★★★★★ | 纯 API + 本地小模型对照 |
| `generative-models/` 生成模型 | ★★★☆☆ | CIFAR 级扩散模型本地可训，刷大规模 SOTA 不可行 |
| `multimodal-llm/` 多模态大模型 | ★★☆☆☆ | 训练基本不可行，走评测/分析/数据路线 |

> 提醒：适配度低不等于不能做，而是必须选对切入角度（各包第 0 节有具体建议）。反过来，适配度高的领域往往竞争也激烈，选题时结合 `FRONTIERS.md` 的冷热分析一起看。
